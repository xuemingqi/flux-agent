# Flux Agent 应用图标

使用内置 imagegen 生成，图标采用蓝色流动的 F 与深色圆角底，沿用界面 `#739df6` 的主色。透明区域保留在圆角底外侧。

`icon.png` 为 1024 × 1024 主图，`icon.icns` 和 `icon.ico` 由 electron-builder 的图标工具从主图转换，分别用于 macOS 和 Windows。开发窗口使用同一 PNG。

## 生成提示词

```text
Use case: logo-brand.
Asset type: production desktop application icon for Flux Agent, macOS Dock and Windows taskbar. One square 1024x1024 icon asset.
Primary request: design a distinctive, beautifully restrained application icon for a developer AI agent called Flux.
Subject: a bold, immediately readable capital F built from a single smoothly folded flowing ribbon. The vertical stem and two rightward bars must read unmistakably as an F at small sizes. Wide strokes, generous negative space, gently rounded terminals, quietly suggesting movement and flow.
Backdrop: one dark graphite rounded-square tile, approximately 84 percent of the square canvas, centered, with macOS-style continuous rounded corners and genuinely transparent space outside the tile. Subtle graphite-to-midnight-blue surface, no busy pattern.
Color palette: cool luminous periwinkle blue inspired by #739df6, with lighter icy blue highlights and a subtle deeper indigo fold. Confident soft satin finish, precise edge lighting, very shallow dimensional depth. No dramatic glow.
Composition: front-on, orthographic, perfectly centered. The F occupies about 56 percent of the tile width and 65 percent of its height. Crisp silhouette readable at 16, 32 and 64 pixels. Balanced whitespace. Pure isolated icon, suitable to install directly.
Constraints: a single icon only, no mockup, no contact sheet, no labels, no small text, no wordmark, no watermark, no robot, no brain, no orbit rings, no star, no extra decorative symbol, no perspective tilt. Transparent outside tile, opaque tile. Sophisticated restrained craft, not a stock generic AI badge.
```
