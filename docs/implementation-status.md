# 当前实施状态

本文件记录当前实现，原始技术方案保持不变。

## 已完成

- 三档权限、工作区选择、独立工作区会话列表，服务端固定每轮权限。工作区会话支持折叠，加号调用 macOS 原生目录选择器。
- 目录列表、文本读取、字面搜索、文件写入和完全权限下的本机 Shell。
- 文件修改前后预览、单次允许／拒绝、持续等待审批与手动取消，审批期间原文和目标路径变化时拒绝写入。
- Drizzle 版本化迁移；SQLite 保存模型配置、工作区、会话、消息、运行步骤、审批和执行凭证。
- 旧 `model.json` 一次性导入，数据库成功提交后删除文件；之后只写 SQLite。
- SSE 重连取完整快照；重启恢复历史，未完成运行中断，旧审批过期，副作用不会自动重放。
- 工作区长期记忆管理页；手动录入立即启用、模型提议先确认，支持来源、版本、有效期、置顶、禁用和删除。
- SQLite FTS5 trigram 检索与短词字面匹配，工作区隔离；只注入已确认且未过期的记忆，记录每次请求实际引用的版本与摘录。
- SQLite 保存原生用户／助手／工具消息，保留工具调用与结果的配对关系；升级前旧轮次兼容文本历史。
- 每次模型调用按字符类别近似估算 token 并预留输出和余量，接近预算时自动摘要压缩，过长前缀分块归纳，保持工具调用和结果配对。当前任务与调整原文始终保留，工具结果不按固定字符数切片；摘要保存到 SQLite 并跨轮次复用，原始消息、工具记录不删除。供应商明确返回上下文溢出时进一步压缩并重试一次模型请求。
- 模型通过 `update_plan` 维护本轮任务计划，支持待开始、进行中、已完成、受阻和跳过；页面以紧凑卡片展示，SSE 实时同步，版本检查防止并行覆盖。
- 回答完成后可评价、补充意见、修改或撤回；反馈绑定运行和 Agent 定义版本，多个页面修改时校验反馈版本。
- 每个项目行悬停显示更多操作与新建会话；支持修改显示名称、移除及重新添加。移除时在单个 SQLite 事务内删除该工作区的全部会话、消息、模型历史、运行、审批和执行凭证；保留工作区 ID、名称、目录和长期记忆，清除记忆的失效来源链接。重新添加不恢复已删除会话。
- 调整方向：持久化收件队列和消息 ID 去重。中止正在输出的模型请求；已开始的单个工具先完成，未开始的旧调用跳过，再优先处理新输入。不重放已经完成的工具；前端同步等待／已开始处理／未处理状态。
- 每条会话悬停显示更多菜单，支持重命名和删除；删除关联消息、运行、工具凭证及子任务，保留文件和长期记忆，清除记忆来源链接。
- 单层多 Agent 编排：`delegate_tasks` 支持并行分工与串行传递结果，每个子 Agent 独立上下文并继承权限。最多同时执行 3 个，其他等待，不设时长或步骤上限；主任务停止时取消并等待全部子任务清理。页面展示独立子任务轨迹，SQLite 保存状态、消息、上下文摘要及结果。
- 兼容模型请求回传完整 `reasoning_content`，并发子任务的字段按请求隔离；子任务交接结果保留完整 JSON。默认不设置单次输出上限，保留手动配置入口，长度截断单独报告。上下文压缩直接收集摘要流，避免额外下载 tokenizer 阻塞收尾；展示分块进度，可刷新恢复。主、子 Agent 与摘要共用模型配置；子任务状态在所属委派工具旁展示，错误分类区分鉴权、限流、上下文和思考协议，失败时仍保存已完成的原生记录。

- 长任务不设命令时长、模型请求时长、整轮时长、图迭代次数、会话轮数或累计回答长度的自动终止限制；保留手动停止和真正错误。命令输出及单工具进度只保留末尾日志，明确标记截断，不以日志量终止工具。

## 当前边界

按当前需求不实现沙箱能力。受限模式的约束由文件工具实现，受限模式不提供 Shell，完全权限命令以宿主用户身份执行，可以联网。此版本适用于单用户本地可信环境。

写入审批绑定运行 ID、工具调用 ID、工作区、参数 SHA-256、目标路径、原文。新审批不按时间过期，服务重启后旧审批仍作废。审批决定先持久化，再释放工具执行。执行凭证在实际操作前落库，结果在操作后落库；崩溃窗口中的 `started` 记录恢复为 `interrupted`，需要用户检查，不推断 exactly-once。

业务数据库为 `FLUX_DATA_DIR/app.db`，启用 WAL、外键和 busy timeout。关键状态与相关消息在短事务内保存；文本及工具进度最多每 500 ms 合并保存，崩溃可能丢失最后一小段展示文本。数据库采用单进程独占连接，防止第二个服务误恢复仍活跃的运行。数据库当前未加密，模型密钥不经 API 返回；本机账号和数据目录的访问权限是凭据保护边界。

已保存会话恢复不等于模型执行续跑。没有引入 LangGraph checkpointer；重启不会重新发送旧工具调用。原生模型历史只复用成功轮次，失败／取消／中断的整轮仍可查看但不用于下一轮；新轮次保存配对工具消息，旧版本已丢失的原生工具历史无法补造。摘要通过 LangChain 模型中间件接入，`ContextCompressor` 单独负责预算、分块、工具配对边界和快照；没有直接使用内置摘要中间件的默认失败回退，避免以错误字符串覆盖原文。摘要是历史资料而非新指令；失败时保留原文并在详情中提示。尚未接入供应商精确 tokenizer。

长期记忆采用工作区内关键词检索、预算内基础记忆补充，以及模型主动调用 `search_memories` 分页查询，未实现 embedding、自动归纳全量聊天、语义去重和冲突合并。每工作区最多 200 条、每条 4000 字符；每次最多引用 6 条且合计 6000 字符，按请求总预算进一步筛选。模型可查询已确认记忆，也可提出候选，不能直接启用或修改用户记忆；候选的来源绑定实际运行。删除记忆同步删除全文索引，但不会抹除原始聊天和已发送的模型上下文。

计划和反馈保存在 `runs.snapshot`，与本轮运行快照一起原子提交，无需新增配置文件；旧记录解析为空值，历史 Agent 版本不会补造。每轮最多 12 个计划步骤，同一时刻最多一项进行中；最新计划在每次模型请求前加入上下文并计入预算。取消、失败或重启中断保留最后状态，不将未完成步骤自动标为完成。当前是模型驱动的计划展示与更新，尚未实现独立 Plan-and-Execute 执行图或自动续跑。

每轮反馈保存一份当前评价与最多 2000 字意见，更新、撤回都会推进版本。仅用户接口可提交反馈，模型不能代替用户评价；反馈不进入模型上下文、不自动写为长期记忆，也不等于训练模型或完成质量评测。

插话通过 `POST /api/runs/:id/steer` 进入当前运行，继承现有权限；模型生成可立即中止，工具在最小执行单元完成后切换，尚未开始的调用跳过；不能代替审批。子 Agent 收到父任务调整后同样在执行边界停止，主 Agent 处理新消息。不设每轮补充条数上限，单条沿用 32000 字符输入限制。`runs.snapshot` 保存消息及处理状态，`model_histories` 保存成功轮次中的补充与原生历史；停止、失败或恢复时将剩余待处理输入标为未处理，不自动续跑。模型请求结束后先检查待处理输入再关闭接收，关闭后的新输入返回冲突并在页面保留草稿，已接收 ID 的重复请求仍返回原记录。

模型传输由 `CancellableOpenAI` 统一处理取消信号，关闭 SDK 的请求计时器和 HTTP 客户端的连接／响应等待计时器；旧 `MODEL_TIMEOUT_MS` 不再生效。供应商、网关、网络故障及本机资源耗尽仍可能导致失败，服务重启也尚不支持任务续跑。日志展示的截断不代表完整日志已落盘，需要完整命令日志时使用文件重定向。

## 后续扩展位置

子 Agent 当前与父运行绑定，支持并行分工和串行结果传递，不支持递归派生、独立后台子会话或服务重启续跑。运行中的子任务在服务重启后标为中断，不自动重放副作用。

| 能力                 | 接入边界                                                          | 下一步约束                                                       |
| -------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------------- |
| 更多模型、多模型切换 | `ModelSettingsStore`、`ModelSettingsService`、模型适配器          | 扩展配置表，不让前端接触凭据                                     |
| MCP 工具             | `AgentDefinition.tools`、`AgentExecutionContext.execute`          | 工具注册后也必须经过宿主权限和审计，不可绕过审批                 |
| 计划执行与工作流     | `RunPlan`、`update_plan`、`AgentRuntime.stream`                   | 复用步骤标识和版本；计划变更不能代替权限与审批                   |
| 运行中补充与消息调度 | `AgentRuntime.supportsSteering`、`AgentExecutionContext.steering` | 新运行时需在可用边界纳入消息并关闭接收；不能静默丢弃或重放副作用 |
| 反馈与固定评测集     | `Run.feedback`、`Run.agent`、`RunManager.saveFeedback`            | 保留运行与定义版本关联；转成记忆或修改策略需明确流程             |
| LangGraph 检查点     | `AgentRuntime.stream`、`RunManager`                               | 独立 checkpoint 存储；恢复审批前核对执行凭证和参数版本           |
| 语义记忆与摘要增强   | `MemoryStore`、`MemoryService`、`ContextCompressor`               | 向量索引、摘要质量评估及多层摘要                                 |
| 多层 Agent 编排      | `delegate_tasks`、`AgentTask`、`AgentExecutionContext`            | 独立子会话与持久恢复，继续继承权限和取消边界                     |
| 事件回放与多进程     | `RunStore`、SSE 快照边界                                          | 增加持久事件序列、执行租约和分页，替换当前内存活动对象           |

下一阶段建议：Skills 与 MCP → 检查点恢复和副作用核对 → 固定评测集与多层编排。沙箱不在实施范围。当前通过实际使用的接口保留扩展位置，没有建立空模块或将后续能力标为已完成。
